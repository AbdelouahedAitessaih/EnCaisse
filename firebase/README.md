# Firebase credentials
#
# 1. Create a project at https://console.firebase.google.com
# 2. Enable Authentication (Email/Password + Google)
# 3. Create a Firestore database
# 4. Add Android app with package: com.encaisse.encaisse
# 5. Add iOS app with bundle: com.encaisse.encaisse
# 6. Download google-services.json → place at android/app/google-services.json
# 7. Download GoogleService-Info.plist → place at ios/Runner/GoogleService-Info.plist
# 8. Run: dart pub global activate flutterfire_cli && flutterfire configure
# 9. Deploy rules: firebase deploy --only firestore:rules
# 10. Create composite indexes from firebase/firestore.indexes.json
#
# DO NOT commit real production credentials to a public repository.
